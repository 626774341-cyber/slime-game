# 🖥️ 史莱姆桌宠（桌面宠物版）

把箱庭史莱姆变成浮在 macOS 桌面上的电子宠物：无边框透明窗口、常驻桌面、可拖动、可换大小。

![预览说明：透明窗口里的 10×10 箱庭小岛，史莱姆在里面生活]

## 功能

- 🏝️ 完整箱庭小岛浮在桌面（草地/小屋/池塘/树木/史莱姆）
- 🌦️ 全窗天气粒子：晴=暖光点（夜晚变萤火虫）、雨=雨丝、雪=雪花，随游戏天气联动
- 📐 相机自动贴合：任意窗口大小、任意缩放，小岛四个角恒定可见
- 🖱️ 全部互动保留：戳 / 拖 / 长按抚摸 / 喂食 / 变身 / 跳舞 / 换装 / 宝宝……
- 🧰 顶栏托盘常驻：显示/隐藏桌宠、换地图（箱庭 ⇄ 轻简）、退出
- 🧲 贴边探头：拖到屏幕边缘，小岛会歪头扒边
- 📴 完全离线：three.js 已打包进应用
- ✕ = 隐藏到托盘（托盘图标随时找回）；拖拽条在窗口顶部

## 构建（macOS Apple Silicon）

不需要 npm / node，一条命令：

```bash
bash desktop-pet/build.sh
```

脚本会自动下载 Electron 预编译包（约 95MB）、注入游戏与配置，
生成 **~/Desktop/史莱姆桌宠.app** 并直接打开。

## 手动构建

1. 下载 [Electron 预编译包](https://github.com/electron/electron/releases)（darwin-arm64 zip）并解压
2. 把 `Electron.app` 拷贝为 `史莱姆桌宠.app`
3. 将本目录（app/ 里的 package.json、main.js、index.html、vendor/）放进
   `史莱姆桌宠.app/Contents/Resources/app/`
4. 双击运行

## 已知限制

- 窗口是方形区域，透明部分也会挡住其后方图标的点击（建议放桌面角落）
- 默认置顶于其他窗口之上
- 首次启动如被 Gatekeeper 拦截：右键 → 打开（仅本地自建时会遇到，一般不会）

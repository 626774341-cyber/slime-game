# 🐾 桌宠更新日志（Desktop Pet Changelog）

这里是**桌面宠物版**专属的版本日志。桌宠版本独立编号（v1.0 起），
主游戏（网页版）的版本日志见仓库根目录的 [CHANGELOG.md](../CHANGELOG.md)。

- 桌宠源码：本目录（app/），一键构建：`bash desktop-pet/build.sh`

## [v1.12.0] - 2026-09-20（最新）

### 新增
- 📂 **五大拖喂玩法完整版**：
  - 🎵 拖音频→学节奏（点 💃 跳舞时按这首歌的节拍哼）
  - 📖 拖文本→学说话（随机选一句变成台词气泡）
  - 🥚 拖文件夹→生蛋（彩蛋砸地孵化出一只小史莱姆宝宝）
  - 🖼️ 拖图片→举牌牌（头顶举着展示，点牌子换一张/收起）
  - 🤢 吃撑打嗝（连拖 5 个打嗝，弹保存框把文件"吐"回来）
- 🍽️ **偏食系统**：每只史莱姆随机最爱和讨厌的文件类别，
  喂对撒花心情+20，喂错嫌弃扣心情，喂两次后偷偷告诉你它最爱什么

### 修复
- ⚽ 追球防卡死（踢球判定 0.95→1.35 + 看门狗轻推）
- 💬 RTF 文件清洗控制码后再学说话

## 版本号规则

- **桌宠功能更新**：v1.1、v1.2 …
- **小修小补**：v1.0.1、v1.0.2 …
- 每次桌宠更新都要：改代码 → 在本文件记录 → 更新 package.json 版本号 → 提交 → 打标签（pet-vX.Y.Z）→ 发 Release

# 🐾 桌宠更新日志（Desktop Pet Changelog）

这里是**桌面宠物版**专属的版本日志。桌宠版本独立编号（v1.0 起），
主游戏（网页版）的版本日志见仓库根目录的 [CHANGELOG.md](../CHANGELOG.md)。

- 桌宠源码：本目录（app/），一键构建：`bash desktop-pet/build.sh`

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，新版本加在最上面。

## [v1.3.0] - 2026-09-19

### 变更
- ❤️ **心情条"低调模式"**：平时半透明几乎看不见，鼠标悬停到上面才完整显示——
  不抢视线，想看再看
- 🧭 **探头动画重做**：史莱姆走到小岛边缘时，身体**压扁摊宽 + 果冻式朝边缘倾倒**，
  探出头去看岛下面是什么（比之前的干压扁生动得多）

### 新增
- 📂 **拖喂玩法**：把桌面上的任意文件拖给史莱姆，它会一口吃掉——
  文件飞进嘴里、爱心彩糖迸出、心情 +12

## [v1.2.0] - 2026-09-19

### 新增
- 👆 **点击穿透**：鼠标不在小岛、按钮或心情条上时，点击会直接落到桌面；
  碰到小岛立刻恢复互动（主进程轮询光标 + 页面椭圆区域判定）
- 💤 **趴边睡觉**：闲置约半分钟后，史莱姆会飘到窗口上沿打瞌睡——
  💤 气泡 + 天气粒子变暗，一动就醒
- 🔁 **开机自启 + 记忆位置**：开机自动出现在上次的角落，窗口大小和位置都会记住；
  托盘菜单新增「开机自启」开关

### 回归
- ❤️ **心情条回归**：顶部居中的半透明小心情条，随时看史莱姆开不开心

## [v1.1.0] - 2026-09-19

### 变更
- 🧹 **互动抽屉去掉白色面板底**：按钮直接悬浮在画面上，不再挡视野
- 🐢 **贴边探头重做**：改为**史莱姆走到小岛边缘时**探头——地图整体朝它所在的
  边缘微微倾斜张望（之前错误地做成了窗口贴边）
- 🚪 **关闭整合为一个**：✕ 就是关闭桌宠（退出应用），不再区分隐藏/关闭；
  托盘菜单保留「显示 / 隐藏」和「换地图」供运行中切换

## [v1.0] - 2026-09-19

首个版本：箱庭史莱姆浮上 macOS 桌面。

### 新增
- 🏝️ **透明置顶窗口**：无边框，箱庭小岛（草地/小屋/池塘/树木/史莱姆）直接浮在桌面上；
  顶部隐形拖拽条可把桌宠放到屏幕任意位置；窗口自由拉伸（默认 700×600，最小 320×280）
- 🌦️ **全窗天气粒子层**：与游戏天气实时联动、淡入淡出切换——
  晴=暖金光点缓缓上飘（夜晚自动变成萤火虫）、雨=雨丝洒满全窗、雪=雪花摇曳
- 📐 **相机自动贴合**：任意窗口大小、任意缩放级别，小岛四个角恒定完整可见；
  滚轮缩放、拖动旋转视角
- 🧰 **顶栏托盘常驻**（蓝色小圆点）：显示/隐藏桌宠、换地图（箱庭 ⇄ 轻简只看史莱姆）、退出
- 🧲 **贴边探头**：拖到屏幕边缘，小岛微微歪头扒着边
- 📴 **完全离线**：three.js 引擎（1.3MB）打包进应用，断网可玩
- 🖱️ **全部互动保留**：戳 / 拖 / 长按抚摸 / 喂食 / 变身（🐻🐰🍄🐢🥕🧁🦆🌵）/ 跳舞 /
  换装 / 宝宝 / 摘星 / 昼夜 / 种花……
- 🚪 **✕ = 隐藏到托盘**（不退出）；再次打开 App 或点托盘都能唤回

### 构建方式
- 一键：`bash desktop-pet/build.sh`（自动下载 Electron 预编译包并生成 ~/Desktop/史莱姆桌宠.app）
- 详见 [README.md](README.md)

## 版本号规则

- **桌宠功能更新**：v1.1、v1.2 …
- **小修小补**：v1.0.1、v1.0.2 …
- 每次桌宠更新都要：改代码 → 在本文件记录 → 更新 package.json 版本号 → 提交 → 打标签（pet-vX.Y.Z）→ 发 Release

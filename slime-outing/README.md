# 🛶 湖泊郊游 · 3D 互动小世界

「箱庭世界 · 3D 史莱姆」的姊妹场景：纪念碑谷式悬浮平顶岛上的**湖泊郊游**——
下沉式湖泊、木栈桥码头、钓鱼、帆船、小动物，全是交互。

## 🌐 线上地址（已发布）

- 湖泊郊游：<https://626774341-cyber.github.io/slime-game/slime-outing/>
- 箱庭世界（原版）：<https://626774341-cyber.github.io/slime-game/>

湖泊郊游左上角「🏠 回箱庭」按钮直连 GitHub Pages 最新部署版（带时间戳绕过缓存）。

## 🚀 本地运行

- 方式一：直接双击 `index.html` 用 Chrome / Edge / Safari 打开（Three.js 走 CDN，需要联网）。
- 方式二（推荐）：起个本地服务器

```bash
cd slime-outing
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 🌐 发布到 GitHub Pages

把 `slime-outing` 整个文件夹复制进 `slime-game` 仓库根目录并推送：

## 🏞️ 场景与彩蛋

- **地形**：程序化起伏草坡 + 雪顶远山环 + 湖心小岛 + 踮脚石过河路线
- **野餐营地**：格子野餐布、野餐篮（点了会弹出更多点心）、收音机 BGM、可点篝火
- **食物**：西瓜 / 面包 / 果汁 / 草莓，点一下抛出去，史莱姆会跑去吃
- **小动物**：小兔子（喂胡萝卜成为朋友并跟随）、鸭子一家（排队的鸭宝宝）、
  小鸟（会落到野餐布上啄食）、蝴蝶（史莱姆发呆时会落在它头上）、青蛙（点一下换荷叶）、
  随机跃出湖面的鱼
- **设施**：木筏小船（点船登船环湖兜风）、荷叶弹弹床、弹弹蘑菇、湖心岛宝箱、气球（放飞再戳破）
- **天气昼夜**：☀️/🌧️/❄️ 三档天气，雪天会堆出雪人、雨停出彩虹；夜晚有萤火虫和星空，
  史莱姆会犯困，点篝火它会来烤棉花糖
- **成长系统**：心情值 + 5 个郊游任务 ⭐，全部完成触发庆典，获得两只史莱姆宝宝

## 🔊 技术要点（人机交互作业可写）

- Three.js r170（ES Module + importmap，零构建）；`MeshPhysicalMaterial` 透射果冻材质
- 顶点级弹簧抖动 + Squash & Stretch 挤压动画；状态机（idle / hop / swim / ride / grab / eat / dance）
- 全程序化资产：Canvas 生成草地/格纹/木纹/表情贴图，Web Audio 实时合成全部音效（无音频文件）
- 粒子对象池（爱心/音符/水花/纸屑/涟漪/萤火虫/雨雪）
- 交互反馈即时可见：音效 + 粒子 + 表情 + 心情四通道同步反馈

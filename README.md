# 🫧 箱庭世界 · 3D 果冻史莱姆

一个基于 **Three.js** 的微缩箱庭小世界，主角是一只果冻质感的 3D 史莱姆。
无需安装、无外部资源文件（模型与音效全部程序化生成），打开网页即可玩。

**🎮 立即游玩：[https://626774341-cyber.github.io/slime-game/](https://626774341-cyber.github.io/slime-game/)**

## 玩法速览

- 🖐️ 按住史莱姆拖动 / 甩出去 · 👆 点一下戳戳它 · 🤚 长按抚摸
- 🤸 蹦床：跳上去越弹越高 · 🎯 秋千：坐上去越荡越高，戳它推一把
- 🎯 点击地面让它跳过去 · ⌨️ 空格超级跳 · B 跳舞
- 🍎 投喂苹果（它会自己跑过去吃）· 🌶️ 辣椒后果自负
- 🏀 玩具球：扔出去，它会自己追着踢
- 🎩 换帽子 · 🎨 换颜色（含彩虹模式）· 🥚 召唤史莱姆宝宝
- 🌙 昼夜切换 · ☔ 晴/雨/雪天气 · 🍄 踩蘑菇弹飞 · 🌱 种花模式
- 💗 心情系统：表情、动作随心情变化 · 📷 拍照模式一键隐藏界面

手机、平板、电脑浏览器均可游玩，桌面端体验最佳。

## 技术要点

- Three.js r170（ES Module + importmap，零构建）
- `MeshPhysicalMaterial` 折射透光果冻材质 + 顶点级弹簧抖动动画
- 程序化贴图工厂（木纹 / 瓦片 / 砖墙 / 草地 / 水面波光，全 Canvas 生成）+ 精细化小屋与场景
- 挤压拉伸（Squash & Stretch）+ 心情数值驱动表情
- 设施互动（蹦床 / 秋千，玩法参考 [Jelly Baby](https://jelly.scottsun.io/)）
- Raycaster 拾取拖拽、实体状态机（free / grab / hop）、领队链跟随 AI
- Web Audio 实时合成全部音效（无音频文件）
- 粒子对象池（爱心/音符/气泡/雨雪/波纹）零 GC 压力
